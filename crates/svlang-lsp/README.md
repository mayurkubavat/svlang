# `svlang-lsp`

SystemVerilog and UVM Language Server Protocol (LSP) engine on the pure-Rust
[`svlang`](https://crates.io/crates/svlang) front end and
[`svlang-lint`](https://crates.io/crates/svlang-lint): document/workspace
symbols, go to definition/declaration/type definition, references, hover,
completion, and live lint diagnostics with quick fixes.

Run via [`svlang-cli`](https://crates.io/crates/svlang-cli) as `svlang lsp`.
