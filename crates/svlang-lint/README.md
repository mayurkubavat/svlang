# `svlang-lint`

Pure-Rust static analysis and auto-fix engine for IEEE 1800-2023 SystemVerilog,
IEEE 1800.2 UVM, synthesizable RTL/FSM/CDC (`RTL-*`), SVA & pre-FPV formal
readiness (`SVA-PRP-*`, `SVA-FPV-*`), and verification methodology (`SVL-*`,
`UVM-*`), built on [`svlang`](https://crates.io/crates/svlang) and
[`svlang-model`](https://crates.io/crates/svlang-model).

For the unified command-line interface (`svlang lint`, `svlang lsp`, `svlang check`),
install [`svlang-cli`](https://crates.io/crates/svlang-cli).
