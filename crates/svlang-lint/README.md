# `svlang-lint`

Static analysis and auto-fix engine for IEEE 1800-2023 SystemVerilog, UVM
(IEEE 1800.2), RTL/FSM/CDC, and formal-readiness checks (`SV-FPV-*`), built on
the pure-Rust [`svlang`](https://crates.io/crates/svlang) front end and
[`svlang-model`](https://crates.io/crates/svlang-model).

For the command-line interface (`svlang lint`), install
[`svlang-cli`](https://crates.io/crates/svlang-cli).
